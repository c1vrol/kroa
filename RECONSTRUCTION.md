# A-1.0.0 reconstruction / Reconstrucción A-1.0.0

## English

This A-1.0.0 snapshot was reconstructed from Kroa's historical specification
and the recorded A-1→A-2 development changes because no recoverable Git history
or preserved original release archive existed. It represents the intended
Alpha-1.0.0 feature set, but it is not an originally preserved tarball.

## Español

Este snapshot A-1.0.0 fue reconstruido desde la especificación histórica de
Kroa y los cambios registrados del desarrollo A-1→A-2, ya que no existía
historial Git recuperable ni un archivo original preservado de la release.
Representa el conjunto de características previsto para Alpha-1.0.0, pero no
es un tarball original preservado.
